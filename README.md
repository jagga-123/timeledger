# TimeLedger

A full-stack time tracker and invoicing app for freelancers, built with the MERN stack (MongoDB, Express, React, Node.js).

## Setup

> This section will be expanded as features are added.

**Prerequisites:** Node.js 20+ and a MongoDB instance (local or Atlas).

### Backend

```bash
cd backend
npm install
cp .env.example .env   # then fill in the values
npm run dev            # http://localhost:5000
```

### Frontend

```bash
cd frontend
npm install
cp .env.example .env
npm run dev            # http://localhost:5173
```
